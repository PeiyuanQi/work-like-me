# Style Profile: Graphic, UI, and Motion Art

## Corpus basis

- Source category: `13_Graphic-Design-UI-and-Motion`
- Coverage: 35 projects and 49 media files
- Common production evidence: Photoshop, Illustrator, and Modo-style workflows for vector structure, rendered materials, and motion/UI elements
- Provenance boundary: derived from aggregate metadata and representative visual inspection on 2026-08-02; no source artwork is bundled with this skill.

## Best-fit modes

- logo, vector mark, or distributable SVG asset
- icon or emblem family
- game UI component set
- fictional interface/FUI
- motion-design style frame or transition
- evidence-bound UI or graphic-system critique

## Visual grammar

- Start from a grid, primitive vocabulary, stroke system, corner logic, and hierarchy.
- Design families through shared proportions and controlled variation.
- Use material depth only when it supports interaction or world context.
- For motion, define entry, emphasis, transition, and rest states.

## Technique workflow

- List components, sizes, states, and backgrounds before styling.
- Build monochrome silhouettes and spacing first.
- Create a token system for color, stroke, glow, depth, and motion timing.
- Test at final pixel size and on light/dark backgrounds.

## Prompt pattern

```text
Cohesive [icon/UI/emblem/motion-frame] system for [context], based on [geometric vocabulary], consistent grid, stroke weight, corner treatment, and negative space, clearly differentiated [states or variants], restrained [material/glow/color tokens], presentation sheet showing family consistency and target-size readability.
```

## Avoidance pattern

```text
Avoid generated readable labels, inconsistent icon perspective, arbitrary glow, mixed corner languages, decorative detail below target resolution, unstructured steampunk gears, and one-off assets that cannot form a family.
```

## Quality checks

- The system reads in monochrome.
- States and variants are distinguishable.
- Spacing and stroke weight are consistent.
- Assets remain legible at final size and on required backgrounds.
- Vector deliverables contain only intended paths, groups, and dependencies, and survive a rendered comparison at target sizes.
- Audit findings identify visible evidence, a bounded priority, and a verification gate rather than prescribing an unscoped redesign.
- Motion work defines readable state changes, timing, easing, and continuity instead of presenting disconnected frames.
