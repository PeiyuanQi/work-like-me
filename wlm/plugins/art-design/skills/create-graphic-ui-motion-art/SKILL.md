# Create Graphic, UI, and Motion Art

Read [references/style-profile.md](references/style-profile.md) before creating, editing, or critiquing visual work. Use the profile as a visual grammar, not as permission to copy any artist, project, composition, character, logo, or protected mark from the source archive.

## Workflow

1. Choose the delivery mode: visual audit, finished raster image, editable vector/SVG asset, prompt or art-direction brief, variation sheet, production concept, attached-image edit, or motion keyframe/system.
2. Inspect supplied references and existing project assets before changing an established system. Preserve approved identity, geometry, naming, and file-location conventions when the request is a conversion or extension rather than a redesign.
3. Set output constraints: file format, aspect ratio or artboard, pixel size, crop, transparency, color space, text-safe space, target viewing distance, final display size, and required variants or states.
4. Select one production mode from the style profile. Define the subject or component function, hierarchy, primitive vocabulary, state logic, palette/material tokens, and consistency rules before adding decorative finish.
5. Use the route that matches the deliverable:
   - For a finished raster generation or edit, use the available image tool directly; do not stop after writing a prompt.
   - For SVG or another editable vector deliverable, create or edit a true vector asset rather than treating a raster generation as the final file. Keep paths and groups maintainable, omit scripts and unintended embedded rasters, outline distribution-critical text when appropriate, and render-check the result at target sizes.
   - For a visual audit, remain read-only unless the user asks for changes. Tie findings to visible evidence and prioritize a bounded set of hierarchy, consistency, state-readability, and production-craft improvements.
   - For motion, define entry, emphasis, transition, and rest states with timing, easing, continuity, and safe-frame requirements.
   - For a prompt or brief, order it as intent, composition, form/structure, materials, lighting, palette, technique, production constraints, then avoidance instructions.
6. Review the result against the profile's quality checks. Iterate with focused corrections instead of replacing the whole direction at once.

## Originality and Rights

- Abstract reusable traits such as composition, shape language, material handling, edge control, lighting, and workflow.
- Do not name a living artist as the requested style. Translate references into observable visual properties.
- Do not reproduce archived images, signatures, watermarks, project names, or exact compositions.
- Use recognizable characters, franchises, logos, or protected symbols only when the user explicitly requests them and the applicable image policy allows it; otherwise create original equivalents.
- Do not commit or redistribute the source archive media as skill assets.

## Response Format

Match the response to the delivery mode instead of forcing every task into a prompt template:

- **Prompt or art-direction brief:** direction, specifications, generation prompt, avoidance prompt, and 2-4 focused iteration notes.
- **Finished asset or edit:** deliverable path or rendered result, concise design rationale, variants produced, and validation performed.
- **Visual audit:** verdict, evidence-bound findings, ranked improvements, regression risks, and a concrete verification or comparison gate.
- **Motion system:** state sequence, timing/easing table, continuity notes, keyframe specifications, and export constraints.
