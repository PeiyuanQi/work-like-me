# Style Profile: Concept Art and Worldbuilding

## Corpus basis

- Source category: `11_Concept-Art-and-Worldbuilding`
- Coverage: 2,871 projects and 3,079 media files
- Common production evidence: Photoshop-centered visual development with Blender, Octane, Modo, 3DCoat, Cinema 4D, 3ds Max, and ZBrush support
- Provenance boundary: derived from aggregate metadata and representative visual inspection on 2026-08-02; no source artwork is bundled with this skill.

## Best-fit modes

- design exploration matrix
- production keyframe
- worldbuilding location or system
- mood and visual-development board

## Visual grammar

- Every image should answer a named question about function, story, culture, scale, or mood.
- Use repeated visual rules across architecture, clothing, props, and environments.
- Show ordinary infrastructure and daily life alongside spectacle.
- Separate exploration outputs from presentation art.

## Technique workflow

- Write the design question, invariants, and variables.
- Generate divergent thumbnail families before converging.
- Use 3D block-ins for perspective and iteration when helpful.
- Annotate decisions in prose outside the generated image; avoid fake text inside it.

## Prompt pattern

```text
Production concept exploring [design question] for an original world defined by [environment, culture, technology, conflict], showing [specific system or story beat], repeated visual rules across [architecture/props/costume], clear scale and function, [exploration sheet or cinematic keyframe format], controlled detail that communicates decisions.
```

## Avoidance pattern

```text
Avoid mood-only images with no design answer, one-off motifs that do not propagate through the world, fake readable annotations, random cultural collage, and polished rendering before major alternatives are explored.
```

## Quality checks

- The design question can be answered from the image.
- World rules repeat coherently.
- Function and daily life are visible.
- Alternatives differ meaningfully rather than cosmetically.
