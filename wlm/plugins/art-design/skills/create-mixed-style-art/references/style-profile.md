# Style Profile: Mixed Style Art

## Corpus basis

- Source category: `15_Other-and-Mixed`
- Coverage: The current source category is empty; use this as the deliberate cross-category fallback rather than an evidence-heavy house style
- Common production evidence: Choose tools from the contributing categories and define a clean handoff between them
- Provenance boundary: derived from aggregate metadata and representative visual inspection on 2026-08-02; no source artwork is bundled with this skill.

## Best-fit modes

- 2D paint over 3D block-in
- graphic system integrated with illustration
- realistic environment plus stylized character
- mixed traditional/digital surface language

## Visual grammar

- Choose one anchor language that controls composition and one secondary language that provides contrast.
- Bridge styles through shared palette, light direction, shape rhythm, or material response.
- Localize the secondary style instead of applying every technique everywhere.
- Make the blend serve the brief rather than novelty.

## Technique workflow

- Name the anchor style, secondary style, and division of labor.
- Define the transition zone between them.
- Test a low-detail composite before committing to finish.
- Unify with final color, edge, texture, and scale passes.

## Prompt pattern

```text
Intentional hybrid image combining [anchor visual language] for [composition/function] with [secondary language] for [specific focal role], unified by [palette/light/shape/material bridge], clear transition rather than random collage, [production format], controlled hierarchy, cohesive final color and edge treatment.
```

## Avoidance pattern

```text
Avoid equal-weight style soup, contradictory lighting, inconsistent perspective, every medium applied everywhere, direct living-artist imitation, and novelty that weakens function or story.
```

## Quality checks

- The anchor style is obvious.
- The secondary style has a defined role.
- Perspective, light, and scale remain coherent.
- Removing either component would meaningfully change the concept.
