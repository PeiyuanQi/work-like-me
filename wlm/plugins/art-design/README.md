# Art Design Plugin

Art direction and visual design skills for generated images, website assets,
game assets, key art, production concepts, and reusable visual systems.

## Skills

- `create-atmospheric-visual-assets`: cinematic website, game, and product assets with tactile materials and functional layout constraints.
- `create-fan-art-visuals`: original tribute, splash, and pop-culture-inspired imagery without artist-style copying.
- `create-sketch-study-art`: gesture, anatomy, value, color, lighting, and exploratory studies.
- `create-vehicle-mecha-designs`: vehicles, spacecraft, industrial machines, robots, and mecha.
- `create-architectural-visuals`: exteriors, interiors, settlements, and cinematic built spaces.
- `create-weapons-props-objects`: weapons, equipment, artifacts, gadgets, and production-ready hero props.
- `create-creatures-animals`: believable creatures, wildlife, monsters, and ecological designs.
- `create-sci-fi-cyberpunk-art`: grounded future-world, industrial-tech, space, and cyberpunk imagery.
- `create-fantasy-mythology-art`: culturally coherent fantasy, folklore, ritual, and mythic scenes.
- `create-environments-landscapes`: natural vistas, locations, weather studies, ruins, and environmental key art.
- `create-characters-portraits`: portraits, character designs, costumes, turnarounds, and production character concepts.
- `create-concept-worldbuilding-art`: visual development, design exploration, production keyframes, and coherent worlds.
- `create-3d-sculpture-models`: sculpture, modeling, topology, materials, grooming, and presentation workflows.
- `create-graphic-ui-motion-art`: icon systems, game UI, emblems, fictional interfaces, effects, and motion frames.
- `create-illustration-storytelling`: narrative illustration, covers, editorial imagery, and emotionally readable story beats.
- `create-mixed-style-art`: controlled cross-category and mixed-media visual directions.

## Workflow Preferences

- Abstract reusable visual grammar from references instead of copying artist names, exact compositions, signatures, logos, characters, or protected marks.
- Start with use case, dimensions, composition, silhouette, and functional constraints before decorative detail.
- Use the category-specific `references/style-profile.md` for technique, prompt, avoidance, and QA guidance.
- When the user requests a finished raster image and image generation/editing is available, generate or edit it directly.
- Keep source archive media out of the plugin; the skills contain only abstracted direction and aggregate provenance.
