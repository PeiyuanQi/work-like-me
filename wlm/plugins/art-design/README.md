# Art Design Plugin

Art direction and visual design skills for generated images, website assets,
game assets, hero art, reusable visual styles, and polished creative assets.

## Skills

- `create-atmospheric-visual-assets`: create or art-direct cinematic website
  and game assets, including hero/key art, section backgrounds, social cards,
  game backgrounds, props, item icons, UI ornaments, texture references, and
  Chinese or East Asian strategy cues when appropriate.

## Workflow Preferences

- Abstract reusable visual grammar from references instead of copying project
  names, logos, exact symbols, or protected assets.
- Start with asset type, production constraints, composition, crop, and
  functional space before prop detail.
- Use original or generated imagery unless source licensing is clear.
- Prefer concrete prompt slots, negative prompts, and visual QA checklists over
  one-off style descriptions.
- Verify generated images at the size and crop where they will actually be used.
